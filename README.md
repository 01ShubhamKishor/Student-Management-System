# Student Management System

A complete web-based Student Management System built using Java Servlet, JSP, MySQL, Tailwind CSS.

## 🚀 Live Features
 **Super Admin Module:** 
   - Dashboard
   - Students [ View Single | View  All  | Add Student | Edit Student | Delete Student | Search ]
   - Courses  [ View Single | View All   | Add Course  | Edit Course  | Delete Course  | Search Course ]
   - Admins   [ View Single | View All   | Add Admin   | Edit Admin   | Delete Admin   | Search Admin  ]
   - Reports  [ Add Fee     | Fee Report | Course Wise fee Report | Student Due Fee Report ]
   - Profile
   
- **Admin Module:** 
  - Students [ View Single | View  All   | Add Student | Edit Student | Delete Student | Search ]
   - Courses  [ View Single | View All   | Search Course ]
   - Admins   [ View Single | View All   | Search Admin  ]
   - Reports  [ Add Fee     | Fee Report | Course Wise fee Report | Student Due Fee Report ]
   - Profile

- **Student Module:**
- Dashboard
- My Profile [ View | Edit ]
- My Course
- Fees
- Change Password
- Logout


## 🛠️ Tech Stack
- Backend: Java 17, Servlet, JSP, JSTL
- Frontend: HTML, Tailwind CSS, JavaScript
- Database: MySQL 8
- Server: Apache Tomcat 9 / 10
- IDE: Eclipse
